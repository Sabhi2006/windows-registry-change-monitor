# Windows Registry Change Monitoring System

A Python-based defensive cybersecurity tool for monitoring selected Windows Registry locations and detecting suspicious or unauthorized changes.

## Objectives

- Monitor autorun registry keys
- Detect registry additions, modifications, and deletions
- Detect suspicious registry changes
- Perform baseline integrity checking
- Generate security alerts and logs
- Generate registry change reports

## Technologies

- Python 3.12
- Windows Registry
- Python winreg
- hashlib
- JSON
- PowerShell
- Streamlit

## Project Status

Completed.

The system monitors selected Windows Registry locations, detects registry changes and suspicious autorun entries, performs baseline integrity checks, and generates security logs and reports.

## Disclaimer

This project is intended for defensive cybersecurity education and controlled testing on authorized Windows systems.
